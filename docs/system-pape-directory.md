# system.pape Paperweight Directory

Paperweight stations report public directory eligibility through the existing telemetry ingest:

```http
POST https://system.paperweighthq.com/api/modules/paperweight/ingest
```

Every ingest request must carry `x-telemetry-secret`. Historically this was one
value (`PAPERWEIGHT_TELEMETRY_SECRET`) shared by every station — anyone who
had it could forge ingest for *any* slug (hijack another station's vanity-URL
redirect target, forge listener/revenue numbers, or squat a slug before its
real owner claims it). system.pape should move to **per-station secrets**,
minted through the self-registration endpoint below, and validate each
ingest's `x-telemetry-secret` against the secret stored for that request's
`stationKey` rather than a single global value.

## Telemetry Secret Registration (Self-Serve)

```http
POST https://system.paperweighthq.com/api/modules/paperweight/register
```

The Paperweight dashboard (desktop app only) calls this once, generating the
secret locally and handing it to system.pape rather than a human copying one
around:

```json
{
  "slug": "rolling-woods-radio",
  "stationKey": "rolling-woods-radio",
  "secret": "<64 hex chars, generated by the station>"
}
```

`stationKey` matches whatever `ingest` will send for this station going
forward (`STATION_KEY` if set, else `STATION_SLUG`, else the station's
anonymous `pwinst_…` install key — see `src/telemetry/reporter.js`
`getStationKey()`). It is usually identical to `slug` but isn't guaranteed to
be, so treat them as two separate fields, not aliases.

**Semantics — trust-on-first-use, matching the existing slug-claim model:**

- If `slug` is unclaimed: store `{ slug, stationKey, secretHash }` (hash the
  secret at rest, e.g. scrypt/bcrypt — never store it plaintext) and respond
  `200 { "ok": true }`. This is the same first-come-wins rule `ingest`
  already applies to slugs; registration just binds a secret to that claim at
  the moment it's made instead of trusting a global secret forever after.
- If `slug` is already claimed **by the same `stationKey`**: treat as a
  rotation — overwrite the stored secret and respond `200`. This lets a
  station that lost its `.env` (reinstall, restore from an old backup) get a
  fresh secret without needing a manual reset.
- If `slug` is already claimed **by a different `stationKey`**: respond
  `409 { "error": "slug already registered by another station" }` — same
  shape and same reason `ingest` already 409s on slug conflicts.
- Validate `slug` server-side with the same reserved-word/profanity rules
  Paperweight itself uses (`src/auth/reserved-slugs.js`) — the caller is a
  station's own dashboard, not a trusted admin tool, so don't assume a
  well-formed or non-hostile `slug`.
- Rate-limit registration attempts (per IP at minimum) to blunt automated
  slug-squatting, since — unlike `ingest`, which just updates a live
  station's own row — a rogue registration can permanently deny a slug to
  its rightful owner if it wins the race.

**Migration note:** keep accepting the legacy shared
`PAPERWEIGHT_TELEMETRY_SECRET` as a fallback on `ingest` for stations that
haven't re-registered yet, then remove it once existing installs have moved
to per-station secrets (dashboard restart is required either way for a
station to pick up a newly-registered secret, so this can be phased with a
deprecation window rather than a hard cutover).

The telemetry payload includes:

```json
{
  "stationKey": "station-or-install-key",
  "slug": "station-slug",
  "name": "Station display name",
  "publicUrl": "https://station.example.com",
  "searchable": true
}
```

`name` comes from `STATION_NAME` and is used as the display name in public search results; consumers fall back to `slug` when it is absent.

`searchable` is read per report by the desktop app. When a creator turns searchability off, the next scheduled report, normally within about 5 minutes, sends `searchable:false` so system.pape can remove the station from the public directory.

## Public Search Endpoint

```http
GET https://system.paperweighthq.com/api/modules/paperweight/stations?q=<query>&limit=20
```

No authentication is required. The response is public read-only directory data, so system.pape should send:

```http
Access-Control-Allow-Origin: *
```

Successful response:

```json
{
  "stations": [
    {
      "slug": "rolling-woods-radio",
      "name": "Rolling Woods Radio",
      "url": "https://rolling-woods-radio.paperweighthq.com",
      "live": true,
      "listeners": 12,
      "nowPlaying": "Late Night Session, Vol. 3",
      "lastSeenAt": "2026-07-06T18:00:00.000Z"
    }
  ]
}
```

## Directory Semantics

Only list stations whose latest ingest has `searchable:true` and a fresh `lastSeenAt`.

Freshness should be approximately 15 minutes, which allows 2-3 missed 5-minute telemetry reports before a station is de-listed.

If the latest ingest has `searchable:false`, de-list the station even if it was previously searchable.

If `q` is empty, return top stations by listener count. If `q` is present, return matching stations, limited by `limit` with a default and maximum of 20.

Stations without a usable public URL or display identity should be omitted from public results.
