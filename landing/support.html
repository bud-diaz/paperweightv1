Help

Support

Paperweight is self-hosted — most issues are answerable without waiting on us.

Before reaching out, check TROUBLESHOOTING.md in your Paperweight install (also linked from the dashboard's Docs modal on desktop). It covers FFmpeg/ffprobe detection, port conflicts, lost dashboard tokens, stream not going live, files not indexing, payment webhook issues, and platform-specific install problems (Windows SmartScreen, macOS Gatekeeper, Linux AppImage/FUSE, Raspberry Pi performance).

Community & General Help

Join the Discord community for setup help, feature discussion, and to see what other creators are running. This is the fastest way to get an answer for most questions.

Bug Reports & Feature Requests

Open an issue on GitHub. Include your OS, Paperweight version, and steps to reproduce. Redact secrets first — see the Security page's reporting guidance (never paste your dashboard token, payment keys, or tunnel tokens).

Station Ops Subscribers

If you're on the paid Station Ops plan, email rollingwoodsmedia@gmail.com for priority support on managed-URL, monitoring, backup, or update issues.

Security Issues

For a security vulnerability, do not open a public issue — email rollingwoodsmedia@gmail.com directly. See SECURITY.md in the repository for the full trust model and reporting guidance.
